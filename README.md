# StockFlow v2 + PackGuard

ระบบจัดการคลังสินค้า + **แพ็กกันของผิด** ตัดสต็อกอัตโนมัติ

## ฟีเจอร์ใหม่: แท็บ 「แพ็ก」

1. กรอกเลขคำสั่งซื้อ / Tracking
2. เลือกแพลตฟอร์ม (Shopee / Lazada / TikTok …)
3. เพิ่มสินค้าจากคลัง + จำนวนที่ต้องแพ็ก
4. สแกนบาร์โค้ด/SKU ทีละชิ้น
   - ถูก → นับจำนวน
   - ผิด → **บล็อก** ไม่ให้ผ่าน (สั่นบนมือถือ)
5. เมื่อครบทุกชิ้น กด **แพ็กครบ · ตัดสต็อก**
   - ระบบสร้าง movement `type: out` ใน Firebase ตามคลังที่เปิดอยู่
   - หมายเหตุ: `PackGuard · <OrderID>`
   - แพลตฟอร์มถูกบันทึกเหมือนจ่ายออกปกติ

## สิ่งที่ยังเหมือนเดิม
- PIN login, Firebase Realtime Database
- รับเข้า / จ่ายออก / ปรับสต็อก
- Dashboard, สินค้า, ภาพรวม

## วิธีใช้
เปิด GitHub Pages ของ repo นี้ แล้วล็อกอิน → แท็บ **แพ็ก**

## หมายเหตุ
- SKU ที่แพ็กต้องมีในคลัง (Firebase skus) ของห้องคลังปัจจุบัน
- ถ้าสต็อกไม่พอ จะไม่ตัดและแจ้งเตือน
- สถิติสแกนผิดเก็บในเครื่อง (localStorage)
