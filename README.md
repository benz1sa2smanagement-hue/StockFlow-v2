# StockFlow v2

ระบบจัดการคลังสินค้า — เวอร์ชันปรับปรุง UI (Quiet Luxury)

## สิ่งที่เปลี่ยนจากเวอร์ชันเดิม
- ดีไซน์ใหม่: Deep Navy + Champagne Gold (Quiet Luxury)
- เอามูลค่าเงินออกจากหน้าแรก (Dashboard)
- รวมมูลค่าเงินไว้ที่หน้าภาพรวม (All Warehouse)
- โปรเจกต์เดิม (Index.html) ไม่ถูกแก้ไข

## วิธีใช้งาน
เปิดไฟล์ `index.html` ผ่าน GitHub Pages หรือเปิดในเบราว์เซอร์โดยตรง

ใช้ Firebase Realtime Database ชุดเดียวกับเวอร์ชันเดิม
